### CPC (Cam Position Changer)
This mod was created using AI but has been tested and is in regular use. 
THE AUTHOR BEARS NO RESPONSIBILITY FOR ANY DAMAGES, ETC. INSTALL AT YOUR OWN RISK.

#### Description
Adjusting the driver's camera position using arrow binds without fly on relative camera.
#### How to use
- The camera must be in driver mode.
- Press `V` to activate the mode.
- Adjust the camera position (moving it wherever you need) using the following keys: Shift + Up/Down/Left/Right/PageUp/PageDown.
#### Installation
The mod archive is available in the Releases section; place it in the game's mods folder.
